# Fast makefun-site drop-in

A faster drop-in for make.fun's own makefun-site 1.0.0: `solve.js` answers
exactly as makefun-site does on every case, with less CPU time.

- Bounty: [Build a static site faster, 22 November 2026](https://make.fun/bounty/site-generator-speed-01-run-20261122)
- Entry: `solve.js` (dependency-free ES module, `run(input)`) + `main.ts` (harness driver)
